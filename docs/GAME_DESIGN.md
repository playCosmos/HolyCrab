# HolyCrab — Game Design v2.1

## 1. 핵심 컨셉

HolyCrab은 라먀니가 엄마의 간장게장 레시피를 **10일 동안 생활 동선을 추적해 조금씩 빼내는 스텔스 코미디**다.

핵심은 세 가지다.

1. 같은 장소를 여러 차례 다시 방문한다.
2. 조사 가능한 기록 중에는 가짜 레시피와 아무 의미 없는 생활 메모가 섞여 있다.
3. 후반으로 갈수록 엄마의 AI가 강해지고 언니까지 추가되지만, 플레이어도 제한적인 일회용 아이템을 얻는다.

## 2. 캠페인 구조

총 10일.

- **집 3회**
  - Day 1 고정
  - Day 2~9 사이 중간 재방문 1회
  - Day 10 최종 작전 고정
- **시장 + 반찬가게 7회**
  - 4회 / 3회로 배분
  - 어느 장소가 4회인지는 캠페인 시드에 따라 달라짐

중간 8일은 가능한 한 같은 장소가 연속되지 않게 배치한다.

집은 스토리의 기준점이고, 시장/반찬가게는 반복 조사 공간이다. 따라서 외부 장소는 방문할 때마다 새로운 핵심 기록을 제공하도록 최대 4개의 방문 템플릿을 가진다.

## 3. 정보 구조

핵심 기록은 진행 조건에 포함된다.

예:

- 간장 : 물 기본 비율
- 꽃게 선택 기준
- 향채 구성
- 매실청 사용
- 간장물 완전 냉각
- 1차 숙성 24시간
- 게 분리 후 간장물 재가열
- 2차 숙성

### 혼선 기록

각 스테이지에는 핵심 기록 외에 혼선 기록을 섞는다.

**가짜 레시피**
- 실패한 실험안
- 오래된 레시피
- 광고/판촉 문구
- 다른 음식의 비율이나 작업표
- 틀린 숙성 시간

**의미 없는 메모**
- 택배 목록
- 주차권
- 직원 교대표
- 야식 메모
- 시장 행사 안내
- 숫자만 적힌 박스 표기

진짜와 가짜는 발견 순간 같은 시각 마커를 사용한다.

직접 모순되는 신뢰도 높은 기록을 나중에 찾으면 과거 가짜 기록에 **다른 기록과 충돌** 표시를 붙인다. 플레이어에게 즉시 정답을 알려주는 대신 교차 검증을 유도한다.

혼선 밀도:
- Day 1~4: 2개
- Day 5~10: 3개

## 4. 엄마 AI

상태:
- Patrol
- Investigate
- Search
- Chase
- Return

행동:
- 시야에 들어오면 의심 증가
- 플레이어 이동 속도가 빠르면 더 빨리 확정 탐지
- 마지막 목격 위치 기억
- 소리가 난 위치 기억
- 놓치면 마지막 위치 주변 다점 수색
- 플레이어 이동 벡터를 이용한 짧은 예측 추적
- 벽/가구 뒤 소리 감쇠
- 날짜와 누적 발각 횟수에 따른 경계도 상승

## 5. 언니

Day 5부터 등장.

- 엄마와 별도 순찰 경로
- 독립적인 기억/시야/청각/의심
- 빠른 추적 속도
- 교차 동선 사용
- 엄마를 유인한 뒤 생기는 빈 공간을 다른 방향에서 압박

## 6. 플레이어 아이템

아이템은 **매일 스테이지 시작 시 1개를 자동 지급**해 인벤토리에 누적한다. 월드에서 별도로 주울 필요는 없다.

지급 규칙:
- 홀수 Day: 포장끈 1개
- 짝수 Day: 담배 1개
- 10일 동안 총 10개 지급
- 포장끈 5개 / 담배 5개
- 사용하지 않은 수량은 다음 날로 이월

### 포장끈

- 단축키: 1
- 사거리: 약 76px
- 가장 가까운 엄마 또는 언니 한 명 대상
- 8초간 이동과 탐지 정지
- 해제 후 경계도 상승
- 해제 위치 주변부터 수색 재개
- 1회 사용 시 1개 소모

의도: 추격을 완전히 삭제하는 무기가 아니라 좁은 통로나 최종 탈출 때 짧은 시간 창을 만드는 비상 수단.

### 담배

- 단축키: 2
- 지속: 7초
- 이동 속도: +45%
- 사용 즉시 큰 소음 1회
- 지속 중 추가 기침 소음 1회
- 1회 사용 시 1개 소모

의도: 도주 능력을 크게 올리는 대신 감시자에게 위치를 노출할 가능성을 만드는 고위험 이동 아이템.

## 7. 장소별 반복 의미

### 집 — 총 3회
1. 시작: 장보기 동선 발견
2. 중간: 집으로 들어온 재료와 흔적 확인
3. 최종: 원본 레시피 확보

### 전통시장 — 3~4회
- 꽃게/간장 선택
- 향채/매실청
- 단골 구매 패턴 교차 검증
- 최종 구매 흔적 재확인

### 반찬가게 — 3~4회
- 냉각/단맛
- 숙성/재가열
- 폐기안과 현재 작업법 비교
- 2차 숙성 반복 공정 확인

## 8. 최종 작전

Day 10 집.

1. 진짜 기록과 혼선 기록을 충분히 교차 확인
2. 최종 원본 조각 확보
3. 숨겨 둔 원본 레시피 직접 획득
4. 엄마 + 언니 동시 감시 회피
5. 필요하면 포장끈/담배를 사용
6. 현관 탈출

퀴즈는 사용하지 않는다.

## 9. 실패

발각 시:
- 해당 날짜 시작점으로 복귀
- 모은 기록 유지
- 주운 아이템과 남은 인벤토리 유지
- 누적 발각 횟수 증가
- 이후 AI 초기 경계도 일부 증가

## 10. 완료 기준

- 10일 캠페인
- 집 정확히 3회
- 시장+반찬가게 정확히 7회
- 외부 장소 4/3 무작위 배분
- 연속 장소 최소화/방지
- 최대 4회 반복 방문에서도 고유 핵심 기록 제공
- 가짜 레시피와 무관한 메모 혼합
- 후반 혼선 밀도 증가
- 엄마 정교 AI
- Day 5 언니 등장
- 매일 시작 시 아이템 정확히 1개 자동 지급
- 10일 기준 포장끈 5개 / 담배 5개 균등 지급
- 포장끈 8초 제압
- 담배 7초 +45% 속도 부스트와 소음 페널티
- 퀴즈 없는 최종 원본 탈출
