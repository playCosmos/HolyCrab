# HolyCrab

**엄마의 간장게장 레시피를 며칠에 걸쳐 훔쳐내는 1인용 스텔스 코미디 게임.**

라먀니는 하루 만에 원본을 찾는 대신 **집 → 전통시장 → 단골 반찬가게**를 여러 날에 걸쳐 반복 방문하며 레시피 조각을 모읍니다. 중간 날짜의 장소 순서는 새 게임마다 섞이며, 후반부에는 엄마뿐 아니라 **언니**까지 라먀니를 추적합니다.

## 바로 플레이

GitHub Pages:

https://playcosmos.github.io/HolyCrab/

Windows에서 저장소를 내려받은 경우 `START_HOLYCRAB.bat`을 더블클릭해도 됩니다.

## 현재 캠페인

기본 캠페인은 총 **8일**입니다.

- Day 1: 집에서 엄마의 장보기 동선 추적
- Day 2~7: 집 / 시장 / 반찬가게를 각각 반복 방문하되 순서는 매번 섞임
- Day 5부터: 언니가 두 번째 추적자로 등장
- Day 8: 집에서 원본 레시피 확보 후 최종 탈출

모은 단서는 날짜가 바뀌어도 유지됩니다. 들켜도 단서는 잃지 않지만 발각 횟수는 누적됩니다.

## 엄마 AI

엄마는 단순 고정 순찰이 아니라 다음 상태를 오갑니다.

- **Patrol** — 지정 동선 순찰 + 지점별 멈춤/주변 확인
- **Investigate** — 들은 소리의 위치로 이동
- **Search** — 마지막 목격/청취 지점 주변을 여러 점으로 수색
- **Chase** — 플레이어의 현재 속도를 이용해 약간 앞쪽을 예측 추적
- **Return** — 수색 실패 후 가장 가까운 순찰 경로로 복귀

날짜가 지날수록 시야, 청각, 이동 속도와 경계도가 증가합니다.

## 언니

Day 5부터 언니가 합류합니다.

- 엄마와 별도 순찰 경로
- 독립적인 시야/청각/의심 수치
- 엄마보다 빠른 추적
- 소리 유인에도 독립적으로 반응
- 한 명을 피해도 다른 한 명의 시야에 들어갈 수 있음

## 조작

- **WASD / 방향키** — 이동
- **Shift** — 살금살금 이동
- **E** — 조사 / 숨기 / 유인 장치 / 원본 레시피 확보 / 출구
- **Tab** — 지금까지 모은 단서 노트

최종 레시피는 별도 퀴즈 없이 단서를 충분히 모은 뒤 직접 확보합니다.

## 개발

런타임 의존성은 없습니다. 테스트:

```bash
npm test
```

테스트에는 충돌/시야/LOS뿐 아니라 캠페인 생성, 날짜 진행, 언니 등장 시점, AI 기억/수색 패턴 검증이 포함됩니다.
