# HolyCrab

**엄마의 간장게장 레시피를 10일에 걸쳐 훔쳐내는 1인용 스텔스 코미디 게임.**

라먀니는 집, 전통시장, 단골 반찬가게를 여러 번 오가며 레시피 조각을 모읍니다. 조사 가능한 종이와 메모가 전부 정답은 아니며, 후반에는 엄마뿐 아니라 **언니**까지 라먀니를 추적합니다.

## 바로 플레이

GitHub Pages:

https://playcosmos.github.io/HolyCrab/

Windows에서 저장소를 내려받은 경우 `START_HOLYCRAB.bat`을 더블클릭해도 됩니다.

## 10일 캠페인

한 캠페인은 정확히 **10일**입니다.

- 집: 총 **3회**
  - Day 1 시작
  - Day 2~9 사이 무작위 시점에 1회 재방문
  - Day 10 최종 작전
- 전통시장 + 단골 반찬가게: 합계 **7회**
  - 한 장소가 4회, 다른 장소가 3회
  - 어느 쪽이 4회가 될지는 시드에 따라 달라짐
- 같은 장소가 연속으로 나오지 않도록 일정 생성
- Day 5부터 언니가 두 번째 추적자로 등장

시장과 반찬가게는 3~4회 반복 방문해도 매번 다른 핵심 기록을 찾도록 방문별 단서 ID와 내용을 분리했습니다. 또한 방문 차수에 따라 임시 장애물, 사용 가능한 숨기 포인트, 환경 유인 장치가 달라져 같은 장소라도 잠입 동선이 그대로 반복되지 않습니다.

## 반복 방문 레이아웃

같은 장소의 구조 전체를 매번 새로 만들지는 않지만, 방문할 때마다 일부 현장 배치가 달라집니다.

- 집 재방문: 장보기 상자 등 생활 물건 추가, 사용할 수 있는 숨기/유인 위치 변경
- 시장: 납품 카트, 장날 적재물, 접은 좌판 등이 차수별로 등장
- 반찬가게: 이동 포장대, 재료 상자, 마감 정리 바구니 등이 통로와 시야를 바꿈
- Day 안내와 상단 미션에는 현재 **현장 상태**가 표시됨
- 추가 장애물은 NPC 전체 순찰 경로 검증을 통과해야 스테이지가 유효함
- Day 10은 별도 최종 배치로 숨기/유인 자원이 줄고, 원본을 꺼내는 순간 소음으로 엄마와 언니가 반응함
- 원본을 확보한 상태로 이어하기 해도 원본 위치의 탈출 구간부터 재개되어 재접속으로 클라이맥스를 건너뛸 수 없음

## 가짜 레시피와 의미 없는 메모

조사 포인트는 진짜 단서만으로 구성되지 않습니다.

- 과거에 폐기된 실패 레시피
- 광고용/인터넷용 레시피
- 틀린 비율과 숙성 시간
- 다른 반찬의 작업표
- 주차권, 택배 메모, 직원 교대표
- 언니의 야식 메모
- 숫자만 적힌 정체불명 쪽지

가짜 레시피는 플레이어가 추론으로 판별해야 하는 퍼즐이 아닙니다. **민트초코, 담뱃재, 치약, 초코시럽, 라면수프**처럼 읽는 즉시 잘못된 내용임을 알 수 있는 괴식/장난 메모로 구성합니다. 주차권·택배·직원 교대표 같은 의미 없는 생활 기록도 섞입니다.

가짜 기록을 진짜 기록과 대조하거나 정답을 검증하는 시스템은 없습니다. 핵심 단서만 진행 조건이고, 가짜/생활 메모는 탐색 중 시간을 빼앗는 방해 요소입니다.

Day 1~4는 하루 2개의 혼선 기록, Day 5 이후에는 하루 3개의 혼선 기록이 섞입니다.

## 엄마 AI

엄마는 다음 상태를 오갑니다.

- **Patrol** — 장소별 순찰, 지점별 멈춤과 주변 확인
- **Investigate** — 들은 소리의 위치로 이동
- **Search** — 마지막 목격/청취 지점 주변을 여러 점으로 수색
- **Chase** — 라먀니의 현재 이동 벡터를 이용한 짧은 예측 추적
- **Return** — 수색 실패 뒤 가장 가까운 순찰 경로로 복귀

벽이나 가구 너머의 소리는 약하게 들리며, 날짜가 갈수록 시야·청각·이동 속도·초기 경계도가 증가합니다.

## 언니

Day 5부터 언니가 합류합니다.

- 엄마와 별도 순찰 경로
- 독립 시야 / 청각 / 마지막 목격 위치 / 의심 수치
- Day 5에는 비교적 완만하게 시작하고 후반으로 갈수록 추적 성능 상승
- 환경 유인은 가까운 추적자가 더 크게 반응해 두 사람의 동선을 분리하는 데 활용 가능
- 한 명을 피하는 동안 다른 한 명에게 발견될 수 있음

## 아이템

아이템은 **매일 맵에 정확히 1개씩 배치**되며 직접 찾아서 주워야 합니다.

- 캠페인마다 포장끈 5개 / 담배 5개가 배치되지만 날짜 순서는 시드에 따라 달라짐
- 같은 종류가 3일 연속 나오지 않도록 일정 생성
- 포장끈과 담배는 각각 **최대 2개까지 보유**
- 보유 한도가 가득 차면 해당 아이템은 맵에 남아 있으며, 하나를 사용한 뒤 다시 주울 수 있음
- 놓치고 다음 날로 넘어가면 그날 아이템은 얻지 못함
- 이미 주운 아이템은 다음 날에도 유지

### 포장끈 — `1`

가까운 엄마나 언니 한 명을 **8초간 움직이지 못하게** 합니다. 풀려난 뒤에는 경계도가 올라가며 주변을 다시 수색합니다.

### 담배 — `2`

사용하면 **7초간 이동 속도 +45%** 부스트를 받습니다. 대신 사용 직후와 도중에 기침 소음이 발생해 엄마나 언니의 조사를 유발할 수 있습니다.

## 조작

- **WASD / 방향키** — 이동
- **Shift** — 살금살금 이동
- **E** — 조사 / 아이템 줍기 / 숨기 / 유인 장치 / 원본 레시피 확보 / 출구
- **1** — 포장끈 사용
- **2** — 담배 사용
- **Tab** — 지금까지 모은 기록
- **Esc** — 일시정지 / 재개

최종 레시피는 퀴즈 없이 원본을 직접 확보한 뒤 탈출하면 됩니다.

## 은신과 환경 유인

- 단서와 가짜 메모는 같은 조사 마커를 사용하며, 조사에는 약간의 정지 시간이 생겨 주변을 확인하고 접근하는 편이 안전합니다.
- 보이지 않는 상태에서 숨는 곳에 들어갈 수 있지만, 수색/조사 중인 추적자가 숨은 곳 바로 앞까지 오면 발각됩니다.
- TV, 차임, 빈 통 같은 환경 유인은 같은 Day에 장치당 한 번만 유효합니다.
- 두 추적자가 있는 날에는 유인 지점에 더 가까운 추적자가 더 강하게 반응하므로, 둘을 한곳에 모으기보다 동선을 갈라놓는 용도로 쓰는 편이 좋습니다.

## 일시정지와 이어하기

- `Esc`로 플레이 중 일시정지 / 재개
- 브라우저 탭이나 창이 비활성화되면 자동 일시정지
- 플레이 중 약 8초 간격과 주요 진행 시점에 자동 저장
- 시작 화면의 **이어하기**로 저장된 캠페인 재개
- 저장 항목: 캠페인 일정, 현재 Day, 확보 기록, 주운 아이템, 사용한 환경 유인 장치, 남은 인벤토리, 원본 확보 여부, 누적 발각, 경과 시간
- 재개 시 NPC는 초기 배치로 재설정되고 라먀니는 해당 Day의 안전한 재진입 지점에서 시작하며, 이미 확보한 진행은 유지
- 단, Day 10 원본을 이미 확보했다면 원본 위치의 최종 탈출 구간에서 재개하고 추적자 반응도 다시 활성화

완주하면 해당 저장은 삭제되고 새 게임은 새로운 일정으로 시작합니다.

## 시야 표시

엄마와 언니의 시야 그래픽은 실제 판정과 같은 벽/가구 차폐를 사용합니다. 화면상 시야 영역이 장애물을 그대로 관통하지 않도록 레이 캐스팅으로 잘라 표시합니다.

## 개발

런타임 의존성은 없습니다.

```bash
npm test
```

테스트는 충돌/LOS/시야뿐 아니라 10일 일정, 집 3회, 시장+반찬가게 7회, 반복 방문 단서 중복 방지, 혼선 기록, 매일 정확히 1개의 아이템 배치, 언니 등장, AI 기억/수색을 검증합니다. 또한 실제 `game.js`를 headless DOM 환경에서 실행해 새 게임 → VN 안내 → 플레이 진입 → Day 피드백 → 일시정지 → 자동 저장 → 재실행 후 이어하기와 최종 탈출 피드백까지 검증합니다.

- GitHub Pages 직접 실행

## 미연시 스타일 스토리 연출

기존 로고 중심 인트로는 제거하고 공통 **VN 장면 시스템**으로 교체했습니다.

- 게임 최초 시작: 라먀니가 10일 작전의 목적과 조작법을 대사로 설명
- 매일 시작: 오늘 장소·목표·아이템 배치를 짧은 독백으로 안내
- 발각: 엄마 또는 언니의 캐릭터 PNG와 전용 대사를 표시한 뒤 같은 날 안전한 재진입 지점에서 재개
- 매일 종료: 핵심 단서, 쓸모없는 메모, 아이템 획득 여부, 오늘 발각 횟수를 결산
- 최종일: 라먀니·엄마·언니의 엔딩 대화 뒤 결과 화면으로 연결

세 캐릭터 초상은 배경이 제거된 PNG 파일을 `assets/vn/`에서 직접 사용합니다.


## 상태 피드백

판정 상태를 별도 연출로 보여주되 실제 AI 상태와 다른 경고는 만들지 않습니다.

- 의심도 상승: 플레이필드 가장자리 위험 비네트가 실제 최대 의심도에 비례해 강해짐
- 의심도 72% 최초 돌파: **발각 임박** 경고음/배너 1회
- `Chase` 진입: 해당 추적자의 추격 시작 배너와 전용 짧은 경고음
- 모든 추적자가 `Chase`에서 벗어남: 시야 이탈 피드백
- 핵심 단서 / 아이템 / 혼선 기록: 종류별 이벤트 배너와 짧은 음색
- Day 시작: 장소와 현재 현장 상태를 중앙 배너로 표시
- Day 10 원본 확보: 최종 탈출 전용 경고음과 **원본 확보 → 탈출** 배너
- 결과 화면: 작전 성공 패널/등급 진입 애니메이션
- OS에서 `prefers-reduced-motion`을 켠 경우 애니메이션 시간을 사실상 제거

상태 변화 배너는 플레이필드 상단, 설명 토스트는 그 아래에 분리해 서로 겹치지 않도록 합니다.
