# HolyCrab

**엄마의 간장게장 레시피를 10일에 걸쳐 훔쳐내는 1인용 스텔스 코미디 게임.**

라먀니는 집, 전통시장, 단골 반찬가게를 여러 번 오가며 레시피 조각을 모읍니다. 조사 가능한 종이와 메모가 전부 정답은 아니며, 후반에는 엄마뿐 아니라 **언니**까지 라먀니를 추적합니다.

## 바로 플레이

GitHub Pages:

https://playcosmos.github.io/HolyCrab/

Windows에서 저장소를 내려받은 경우 `START_HOLYCRAB.bat`을 더블클릭해도 됩니다.

## 10일 캠페인

한 캠페인은 정확히 **10일**입니다.

- 집: 총 **3회**
  - Day 1 시작
  - Day 2~9 사이 무작위 시점에 1회 재방문
  - Day 10 최종 작전
- 전통시장 + 단골 반찬가게: 합계 **7회**
  - 한 장소가 4회, 다른 장소가 3회
  - 어느 쪽이 4회가 될지는 시드에 따라 달라짐
- 같은 장소가 연속으로 나오지 않도록 일정 생성
- Day 5부터 언니가 두 번째 추적자로 등장

시장과 반찬가게는 3~4회 반복 방문해도 매번 다른 핵심 기록을 찾도록 방문별 단서 ID와 내용을 분리했습니다.

## 가짜 레시피와 의미 없는 메모

조사 포인트는 진짜 단서만으로 구성되지 않습니다.

- 과거에 폐기된 실패 레시피
- 광고용/인터넷용 레시피
- 틀린 비율과 숙성 시간
- 다른 반찬의 작업표
- 주차권, 택배 메모, 직원 교대표
- 언니의 야식 메모
- 숫자만 적힌 정체불명 쪽지

발견 순간에는 진짜/가짜를 표시하지 않습니다. 모두 동일하게 **기록**으로 노트에 들어갑니다.

이후 다른 날에 확보한 신뢰도 높은 기록과 직접 충돌하면 이전 기록에 **다른 기록과 충돌** 표시가 붙습니다. 플레이어는 한 장을 믿는 대신 여러 날의 기록을 교차 확인해야 합니다.

Day 1~4는 하루 2개의 혼선 기록, Day 5 이후에는 하루 3개의 혼선 기록이 섞입니다.

## 엄마 AI

엄마는 다음 상태를 오갑니다.

- **Patrol** — 장소별 순찰, 지점별 멈춤과 주변 확인
- **Investigate** — 들은 소리의 위치로 이동
- **Search** — 마지막 목격/청취 지점 주변을 여러 점으로 수색
- **Chase** — 라먀니의 현재 이동 벡터를 이용한 짧은 예측 추적
- **Return** — 수색 실패 뒤 가장 가까운 순찰 경로로 복귀

벽이나 가구 너머의 소리는 약하게 들리며, 날짜가 갈수록 시야·청각·이동 속도·초기 경계도가 증가합니다.

## 언니

Day 5부터 언니가 합류합니다.

- 엄마와 별도 순찰 경로
- 독립 시야 / 청각 / 마지막 목격 위치 / 의심 수치
- 엄마보다 빠른 추적
- 엄마와 독립적으로 소리 유인에 반응
- 한 명을 피하는 동안 다른 한 명에게 발견될 수 있음

## 아이템

아이템은 **매일 시작할 때 정확히 1개씩 자동 지급**됩니다. 홀수 날은 포장끈, 짝수 날은 담배가 지급되어 10일 동안 두 종류를 5개씩 받을 수 있습니다. 사용하지 않은 아이템은 다음 날에도 유지되고, 사용 시 1개씩 소모됩니다.

### 포장끈 — `1`

가까운 엄마나 언니 한 명을 **8초간 움직이지 못하게** 합니다. 풀려난 뒤에는 경계도가 올라가며 주변을 다시 수색합니다.

### 담배 — `2`

사용하면 **7초간 이동 속도 +45%** 부스트를 받습니다. 대신 사용 직후와 도중에 기침 소음이 발생해 엄마나 언니의 조사를 유발할 수 있습니다.

## 조작

- **WASD / 방향키** — 이동
- **Shift** — 살금살금 이동
- **E** — 조사 / 숨기 / 유인 장치 / 원본 레시피 확보 / 출구
- **1** — 포장끈 사용
- **2** — 담배 사용
- **Tab** — 지금까지 모은 기록

최종 레시피는 퀴즈 없이 원본을 직접 확보한 뒤 탈출하면 됩니다.

## 개발

런타임 의존성은 없습니다.

```bash
npm test
```

테스트는 충돌/LOS/시야뿐 아니라 10일 일정, 집 3회, 시장+반찬가게 7회, 반복 방문 단서 중복 방지, 혼선 기록, 매일 정확히 1개의 아이템 지급, 언니 등장, AI 기억/수색을 검증합니다.
