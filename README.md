# HolyCrab

**HolyCrab** is a compact single-player stealth-comedy game for Windows browsers.

You play as **라먀니 (Ramyani)**, sneaking through the house at night to reconstruct and steal Mom's legendary soy-marinated crab recipe without being caught.

The repository is currently being bootstrapped into a complete, no-install HTML5 game. See `docs/GAME_DESIGN.md` once the implementation branch lands.
